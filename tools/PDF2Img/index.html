支持 PDF、DOCX、PPTX（旧版 .doc / .ppt 暂不支持纯前端解析）
格式说明：
· PDF / PPTX 支持逐页导出与拼接长图。
· DOCX 由 docx-preview 渲染为 HTML 后整体截图，不支持精确逐页分割，请使用「导出长图」获取完整内容。
· 旧版 .doc / .ppt 为二进制 OLE 格式，纯前端无可靠解析方案，请另存为 .docx / .pptx 后重试。
· 拼接长图受浏览器画布限制（单边 ≤ 32767、面积 ≤ 2.68 亿像素），超限会提示并自动降低分辨率。
