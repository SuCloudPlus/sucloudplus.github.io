支持 PDF、DOCX、PPTX（旧版二进制 .doc / .ppt 请先另存为 .docx / .pptx）
格式与快捷键说明：
· PDF / PPTX 支持逐页导出、点击缩略图全屏预览与拼接长图。
· 全屏预览快捷键：← / → 上/下一页，Home / End 首/尾页，PageUp / PageDown 前/后 5 页，Esc 关闭。
· DOCX 由 docx-preview 渲染为 HTML 后整体导出长图，不支持精确逐页分割。
· 旧版 .doc / .ppt 为二进制 OLE 格式，纯前端无可靠解析方案，请另存为 .docx / .pptx 后重试。
· 拼接长图受浏览器画布限制（单边 ≤ 32767、面积 ≤ 2.68 亿像素），超限会提示并自动降低分辨率。
